# Jetson mesh preview and layout overlays — 2026-11-07

Implemented and exercised on the actual desktop GUI using the Jetson U13 crop.

- Preview mesh meshes the selected copper and writes a standard layer mesh and cropped layout without moment filling, linear solving or GPU initialization. Preview is kept in a separate subfolder from solved results. A cached board-JSON preview took approximately 3 s; raw KiCad import adds its own cost.
- Layout / mesh offers layer and mesh selection. The preview summary reports triangle count, longest edge and minimum angle by layer.
- Field overlay projects a selected copper layer under the horizontal field scan, with field opacity and component controls. Simulated copper is cyan, unsimulated layout context grey and selected converter/capacitors gold. This highlights model participation, not a thresholded current-density map. Cross-sectional field cuts retain their existing physical cut behavior.
- Component silhouettes are shown in 2D/3D, with orientation and bottom-side placement. Dimensions come from nominal package names when available; otherwise pad envelopes and assumed height. They are display artifacts and do not change the electrical model. Jetson's crop includes 16 component silhouettes, with U13/C46/C49 selected.
- PNG and animation exports retain the chosen layer, opacity and component settings. 04-exported-overlay.png is an exported field plot, independent of GUI screenshots.
- Use board and rail in Power Integrity transfers the original board, input net and ground reference. DC sources/loads remain explicit. Unknown transferred supply voltage must be entered before a DC run; the switching-current pulse is not automatically a DC load.

The same U13 model (10,045 triangles, ten layers, 252 via segments, 500 kHz and 1 MHz, heights 1/3 mm) was solved before and after layout export changes. Copper R, L and sampled peak H are unchanged exactly. This is regression evidence, not validation of real converter behavior. The final relevant suite passed 88 tests: CLI/preview contracts, layer z coordinates, overlays and holes in KiCad/model axes, component geometry, exported field frames, GUI integration and PI handoff. Existing hardware-probe subprocess cleanup warnings occur in the GUI tests.

Reproduction uses the existing exported Jetson board JSON, regenerated by the earlier roadmap scripts from the installed KiCad demo. CLI examples:

    kicad2ems/.venv/bin/python -m mom25d.mqs board.json --converter U13 --vin VCC --capacitors C46,C49 --dmax 2 --fine 1 --margin 2 --preview --out preview
    kicad2ems/.venv/bin/python -m mom25d.mqs board.json --converter U13 --vin VCC --capacitors C46,C49 --dmax 2 --fine 1 --margin 2 --harmonics 1,2 --heights 1,3 --scan-points 17 --fill-workers 8 --out result

See mom25d/docs/quasistatic-validation.md for convergence, independent DC/analytic references, conservation/passivity checks and physical correlation. A full shared Power analysis workspace can reuse this board/layout/component context while presenting DC drop, PDN impedance and switching-field modes with their own excitations and model assumptions. Whole-board full-wave runs at the same low frequencies need not be the primary validation reference.

Source changes and these new artifacts are uncommitted. The GUI is left open on the Jetson field overlay. On this desktop it is launched with QT_QPA_PLATFORM=xcb QT_XCB_GL_INTEGRATION=xcb_glx PYOPENGL_PLATFORM=glx for working OpenGL rendering.
